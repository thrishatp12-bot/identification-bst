# Identification Number Management Using BST

## Problem Statement
A government database stores the identification
numbers A102, A25, A7, B100, B12, A120, B3 and A45.

The objective is to organize these numbers using
a Binary Search Tree (BST).

## Objectives
- Implement BST insertion.
- Display inorder traversal.
- Compare BST search with linear search.
- Count the comparisons required for searching.
- Analyse the effect of insertion order and key length.
- Study the best-case and worst-case complexities.

## Programming Language
C

## Data Structure
Binary Search Tree

## Search Methods
1. Binary Search Tree Search
2. Linear Search

## Complexity Analysis
BST search:
- Best case: O(1)
- Average case: O(log n) for a balanced tree
- Worst case: O(n)

Linear search:
- Best case: O(1)
- Worst case: O(n)
